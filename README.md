# Linux Server Health Monitoring Tool

## Project Overview

This project is a Bash-based Linux Server Health
Monitoring Tool.

It collects important system information and
displays a health report directly in the terminal.

## Features

- Displays current date and time
- Checks server uptime
- Displays CPU load averages
- Monitors RAM usage
- Checks disk space usage

## Technologies Used

- Linux
- Bash Scripting
- Git
- GitHub

## How to Run

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate into the directory:

cd linux-server-health-check

Give execution permission:

chmod +x health_check.sh

Run the script:

./health_check.sh
